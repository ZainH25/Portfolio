# Static assets

Files here are served from the site root. Example: `public/images/portrait/myphoto.jpg` → `/images/portrait/myphoto.jpg`.

## Folders

| Folder | Use |
|--------|-----|
| `images/portrait/` | Headshot + project art (mapped in `lib/project-images.ts` and `site.portraitUrl`) |
| `images/projects/` | Optional extra screenshots |
| `documents/` | PDFs (e.g. `resume.pdf` → `/documents/resume.pdf`) |
